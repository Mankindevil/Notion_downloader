# Fonts — curated reference

Pick a **display font** (the hero word) and pair with a **support font** (subtitle / romaji). The display font carries the personality; the support font is the foil. Mismatched personalities feel chaotic; matching them feels flat. Aim for *intentional contrast*.

All fonts here are on Google Fonts unless noted. Load via `<link href="https://fonts.googleapis.com/css2?family=…">`.

**Never use:** Inter, Roboto, Arial, Helvetica, system-ui, generic serif. They read as "I did not pick a font."

## Pairing rules

1. **Weight contrast** — heavy display + medium support, or thin display + heavy support. Same weight × different family = mush.
2. **Family contrast** — display serif + support sans, or display sans + support serif. Two serifs is risky unless one is decorative.
3. **Width contrast** — wide display + narrow support, or vice versa. Adds rhythm.
4. **One personality wins** — if the display is loud, the support must be quiet. Never two loud fonts.
5. **CJK + Latin** — use a CJK display font for kanji/katakana AND a separate Latin display font for romaji. Don't rely on a single font's Latin glyphs unless it has them designed (e.g. Noto Serif JP's Latin is competent).

## Per-character cues (examples)

- **Bubbly cheerful anime girl** → Chewy / Fredoka + Mochiy Pop One; support with M PLUS Rounded 1c
- **Cool elegant magical-girl** → Cormorant Garamond italic + Cinzel Decorative (small accents); support with Marcellus SC
- **Tan mischievous "dark side" version of a character** → italic Cormorant or Bodoni Moda + tight tracking, gold accents
- **Cyberpunk operator** → Audiowide / Orbitron + Space Mono support
- **Magical-girl heraldic** → Cinzel Decorative + Cinzel + a script accent (Sail or Tangerine)
- **Y2K idol** → Rampart One / Modak with chrome gradient + Space Mono romaji
- **Soft pastel slice-of-life** → Caveat Brush or Shadows Into Light + Quicksand support
- **Action/sport shounen** → Bungee + Bowlby One drop shadow + Anton support
- **Retro-diner waifu** → Lobster or Pacifico + Tenor Sans support

## Loading multiple Google Fonts at once

Combine families in one URL to keep network round-trips down:

```html
<link href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,700;1,700&family=Cinzel+Decorative:wght@700&family=Marcellus+SC&family=Noto+Serif+JP:wght@700;900&display=swap" rel="stylesheet">
```

Use `display=swap` so text renders with fallback while the web font loads, and screenshots don't capture invisible text.
